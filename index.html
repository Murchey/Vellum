背景 = 语义槽位 + 自定义图/色

番茄没有 day/night 资源限定符切换，而是 5 套语义色槽位由代码驱动；自定义背景走独立的图/纯色配置，分 dark / light / standard 三档底色类型来决定正文墨色。

护眼是覆盖层，不是换背景

is_eye_protect_open 控制一层 alpha 0.15 的半透明色层叠在正文之上；亮度则是窗口级 screenBrightness，不动用户系统设置。两者与背景互相独立。

朗读 = 句级断句 + 双击触发

听书模式下双击取点击处句子触发 TTS，双击窗口 200ms（单击动作延迟到窗口结束）；句界由 native 分词器 libtokenizer.so 承担。Vellum 可用 Dart 句界正则 + 现有 TTS 服务复刻这套机制。

1.2 交互与机制建议

  1. 三段式设置行（对齐番茄文案反推的功能清单）：预设色点一排 + 「自定义（纯色 / 相册图）」+ 亮度滑条 + 护眼开关。自定义背景支持「先预览后应用」，照搬 PreviewCustomBackgroundView 的心智。
  2. 底色三槽位而不是自动猜色：自定义图/色由用户选 亮 / 暗 / 中性 一档（默认按图片平均亮度给推荐），正文墨色、页脚胶囊、顶栏按钮一律按槽位取色 —— 这正是 ReaderBgColorType 的作用。
  3. 护眼、亮度、背景互相独立：护眼永远是叠加层（0.15），亮度走窗口属性，背景只管纸。三者可任意组合，互不覆盖。
  4. 本地自定义 = 本地文件：图片经 file_picker（Vellum 已有依赖）复制进应用私有目录 backgrounds/，引用文件名而非绝对路径；纳入「存储管理」的占用统计与清理。纯色自定义用 hex 输入 + 小色板即可，不必引入取色器依赖。
  5. 按书覆盖（番茄「本书单独设置」的等价物）：全局默认 + 可选的本书覆盖，存进现有 ReadingState 旁的独立字段。

② 背景渲染器 —— 背景 / 护眼 / 亮度三层，互不干扰

Widget buildReadingSurface({
  required ReaderBackground background,
  required Widget child,
}) {
  final paper = switch (background.kind) {
    BackgroundKind.preset  => VellumTheme.readerPaper(background.presetId),
    BackgroundKind.color   => Color(background.colorValue ?? 0xfff7e4cf),
    BackgroundKind.image   => null, // 交给 DecorationImage
  };
  return Stack(fit: StackFit.expand, children: [
    DecoratedBox(
      decoration: BoxDecoration(
        color: paper,
        image: background.kind == BackgroundKind.image
            ? DecorationImage(
                image: FileImage(File(background.imagePath!)),
                fit: BoxFit.cover,
                // 大图降采样，避免解码整图（与 cacheWidth 同思路）
              )
            : null,
      ),
      child: child,
    ),
    if (background.eyeCare)
      // 番茄 getEyeProtectedView：覆盖层 alpha 0.15，不改背景
      const IgnorePointer(child: ColoredBox(color: Color(0x26d9a441))),
  ]);
}

2.2 可借鉴清单（按收益排序）

  1. 句级断句 + 句级高亮：Vellum 的 tts_text.dart 已有按句切分；补一个「点击处句子提取」，朗读时把当前句作为 ReaderParagraph(highlights: [当前句]) 传入 —— 高亮渲染器已经存在，零新增渲染代码。
  2. 双击听书手势：在 reader_gestures.dart 引入 200ms 双击窗口；单击（翻页 / 呼出菜单）延迟到窗口结束再分派，双击命中则朗读该句。这是番茄手感的关键，也是最容易做错的一处。
  3. 字幕行：朗读条上方加一行当前句字幕（等价番茄 17sp 字幕字号），大字号模式下尤其有用；复用 TtsBar 的胶囊容器即可。
  4. 句粒度队列：把现有 SpeakableSegment（段粒度）细化到句粒度（paragraphIndex + sentenceIndex 进缓存 key），预取下一句；长段合成时延从秒级降到句级。
  5. 按书记忆：key_is_tts 的等价物 —— 记住每本书是否在听书、听到哪句，重开书给「继续听」。
  6. 输入矩阵补齐：听书中音量键 = 上一句/下一句（复用 reader_platform 的 volumeKey 回调），沿用 300ms 节流。

2.3 代码建议

① 点击处句子提取 —— tts_text.dart 增补

/// 给定段落文本与点击的字符偏移，返回该句的 [start, end) 区间。
/// 句界正则即番茄 libtokenizer.so 的 Dart 近似：中英句末标点 + 收尾引号。
({int start, int end})? sentenceAt(String text, int offset) {
  if (text.isEmpty) return null;
  final o = offset.clamp(0, text.length - 1);
  const end = r'[。！？!?…；;][”’"\')\]]?';
  final ends = RegExp(end).allMatches(text).toList();
  int start = 0, stop = text.length;
  for (final m in ends) {
    if (m.end <= o) start = m.end;
    if (m.end > o) { stop = m.end; break; }
  }
  while (start < text.length && text[start] == ' ') start++;
  return stop > start ? (start: start, end: stop) : null;
}

机制对照

  • 双击窗口 200ms · 单击延迟分派
  • 句界断句 ≈ libtokenizer.so 的 Dart 近似
  • 当前句 = highlights 条目，复用现有渲染器
  • 字幕行 ≈ 番茄 17sp 字幕字号
  • 音量键上一句/下一句 · 节流 300ms（真机侧）

机制对应到 Vellum 现成模块：tts_client.dart（合成）、tts_cache.dart（缓存）、tts_audio_handler.dart（后台/通知栏）、reader_platform.dart（音量键回调）。

2.5 不建议照抄

  • native 分词器（libtokenizer.so + 词典）：为断句引入 so 与词典包不值当，Dart 句界正则已覆盖中英混排；只有做「按词断行排版」才需要分词。
  • 菜单 Dialog 挂 decor：番茄用它做触摸仲裁；Vellum 的 Stack overlay + 滑动关闭已可用，不必为此重构。
  • Lynx 自定义标签 / 广告位 / 听书页内嵌商城：与本地离线阅读无关。
  • 番茄的橙色品牌体系：只取参数与机制，不取 #FFFA6725 品牌色；Vellum 保持朱砖 #A33D2E。
