# VELLUM 长线重构决策摘要（2026-10-06）

## 范围与约束

- 先完善 VELLUM，再处理 `AiChatApp` 与 `inkqilin-ledger` 的 UI；三个工程互不搬移业务数据。
- 使用 Android Studio 模拟器验证 Android 主路径。跨平台代码保持 Flutter 可编译，系统小组件第一阶段实现 Android 原生小组件。
- 不执行 Git 提交、推送、合并或远程仓库操作。需要回退时只建立本地备份目录，并在改动前复制将被修改的文件。
- 所有临时解包、截图、构建中间产物在验证结束后删除；长期保留的只有源代码、测试和本决策摘要。

## 视觉决策

- VELLUM 采用 Cupertino-first 的 Apple 视觉：系统字号、4/8 间距、18/24 圆角、低对比分隔线、轻量毛玻璃感；应用壳层和交互使用温暖羊皮纸与陶土红棕，正文阅读纸张继续遵循阅读主题色。
- 深浅色共用同一组语义 token，颜色只在主题层解析；交互热区至少 44 dp。
- 字体面板参考番茄的“整行预览 + 当前勾选 + 立即反馈”，增加字体分类、预览短句和当前字体状态，减少拥挤卡片。
- 笔记面板改为“引用内容 → 类型/操作 → 编辑区”的纵向层次，列表采用时间与章节信息的轻量副文案，编辑和删除均保留可恢复反馈。

## 数据与安全决策

- 本地优先：备份包包含书库索引、阅读状态、阅读统计、笔记、设置和用户字体；缓存与构建产物不进入备份。
- 本地备份采用 ZIP；可选 AES-256-GCM 加密，密码只在当前操作生命周期存在。
- 云备份使用统一对象存储适配器，兼容腾讯云 COS 与阿里云 OSS 的 HMAC 签名；SecretId/SecretKey 仅保存在系统安全存储，导出包与日志永不写入密钥。
- 云操作默认为用户显式触发，自动备份必须由用户开启；上传失败不影响本地数据。

## 性能决策

- 大书读取采用索引与正文分离、可取消的后台解码、分页按需生成；界面先显示书籍元数据和骨架，再逐步填充正文。
- 搜索与统计不能在首帧同步扫描全书；所有耗时操作提供阶段文案或进度。

## 交付顺序

1. 建立共享 UI token、改造字体面板与笔记面板。
2. 加入 VELLUM 备份核心与设置入口（先本地，再 COS/OSS）。
3. 优化阅读计时与统计页面、验证大书加载路径。
4. 添加 Android 系统小组件并在模拟器安装验证。
5. 单独建立 `AiChatApp` 与 `inkqilin-ledger` 的 UI 决策摘要，按各自技术栈重构公共主题与高频页面。

- 笔记目录改为引用块、笔记正文、段落元信息和独立删除操作的卡片布局；空状态增加清晰的引导图标。

- 书籍内容 JSON 解码迁移到 isolate，避免大书打开时在 UI isolate 同步 `jsonDecode`。
- Android 小组件以中性卡片 + 主操作胶囊按钮打开 VELLUM，已完成 debug APK 构建和模拟器安装。

- 阅读页增加轻量计时胶囊，展示本次阅读与今日累计时间；计时暂停、后台落盘和统计详情继续由原有服务统一管理。

## 持续 UI 打磨（2026-10-06）

- 阅读器设置的每个子页在切换时回到顶部，避免保留上一页滚动偏移导致标题返回键落在滚动视口之外；返回、关闭、分组选项和字号控制统一采用至少 44 dp 的触摸热区。
- 设置页的分组列表使用独立卡片表面承载条目，页面背景与条目背景分离，确保浅色和深色模式下都有清晰的信息层级。
- 书库继续使用响应式列数和封面比例：窄屏优先保证封面可读，平板与桌面逐步增加列数；长标题与元数据统一省略，避免网格出现横向溢出。
- 笔记卡片使用轻微纸面对比、引用块和独立删除热区；目录搜索步进、紧凑目录关闭和笔记删除均保持 44 dp 触摸目标，避免窄屏误触。

## 阅读页与应用壳层统一（2026-10-06）

- 复核番茄解包资料后保留其机制：正文纸张可独立选择，阅读菜单覆盖在正文之上，章节、进度、书签和设置共享当前阅读状态；不复制番茄代码或品牌资源。
- VELLUM 的交互强调色统一使用应用壳层陶土红棕（浅色 `#A95C46`、深色 `#D8896C`）。番茄橙色仅作为逆向参考 token 保留，避免阅读页与书库/设置页出现两套品牌色。
- 阅读纸张、正文墨色和暗色对比度继续由 `ReaderBackground` 与 Fanqie 标准纸张 token 管理；这样用户的阅读舒适度设置不会被壳层统一色彩覆盖。

## 温暖羊皮纸主题最终决策（2026-10-06）

- 字体选择页和字体管理页都从主题语义 token 解析背景、卡片、文字、分隔线和交互色；字体选择页的当前项同时使用陶土色填充、细边框、名称高亮和勾选图标。
- 阅读纸张继续保留番茄标准白、米黄、绿、蓝、夜间和炭黑色板；阅读纸张与菜单壳层分离，字体预览即时反馈，交互热区保持至少 44dp。
- Android 小组件同步使用同一套暖色资源：浅色 `#F7F3ED/#FFFDF8/#A95C46`，深色 `#151311/#211E1A/#D8896C`，文字与 Flutter 壳层 token 对齐。
- 不迁移阅读状态 JSON，不改变备份格式，不改变字体存储格式；旧阅读纸张归一化逻辑继续只处理既有历史值。
