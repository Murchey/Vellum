# VELLUM 长线重构决策摘要（2026-10-06）

## 范围与约束

- 先完善 VELLUM，再处理 `AiChatApp` 与 `inkqilin-ledger` 的 UI；三个工程互不搬移业务数据。
- 使用 Android Studio 模拟器验证 Android 主路径。跨平台代码保持 Flutter 可编译，系统小组件第一阶段实现 Android 原生小组件。
- 不执行 Git 提交、推送、合并或远程仓库操作。需要回退时只建立本地备份目录，并在改动前复制将被修改的文件。
- 所有临时解包、截图、构建中间产物在验证结束后删除；长期保留的只有源代码、测试和本决策摘要。

## 视觉决策

- VELLUM 采用 Cupertino-first 的 Apple 视觉：系统字号、4/8 间距、18/24 圆角、低对比分隔线、轻量毛玻璃感；应用壳层和交互使用温暖羊皮纸与陶土红棕，正文阅读纸张继续遵循阅读主题色。
- 深浅色共用同一组语义 token，颜色只在主题层解析；交互热区至少 44 dp。
- 字体面板参考番茄的“整行预览 + 当前勾选 + 立即反馈”，增加字体分类、预览短句和当前字体状态，减少拥挤卡片。
- 笔记面板改为“引用内容 → 类型/操作 → 编辑区”的纵向层次，列表采用时间与章节信息的轻量副文案，编辑和删除均保留可恢复反馈。

## 数据与安全决策

- 本地优先：备份包包含书库索引、阅读状态、阅读统计、笔记、设置和用户字体；缓存与构建产物不进入备份。
- 本地备份采用 ZIP；可选 AES-256-GCM 加密，密码只在当前操作生命周期存在。
- 云备份使用统一对象存储适配器，兼容腾讯云 COS 与阿里云 OSS 的 HMAC 签名；SecretId/SecretKey 仅保存在系统安全存储，导出包与日志永不写入密钥。
- 云操作默认为用户显式触发，自动备份必须由用户开启；上传失败不影响本地数据。

## 性能决策

- 大书读取采用索引与正文分离、可取消的后台解码、分页按需生成；界面先显示书籍元数据和骨架，再逐步填充正文。
- 搜索与统计不能在首帧同步扫描全书；所有耗时操作提供阶段文案或进度。

## 交付顺序

1. 建立共享 UI token、改造字体面板与笔记面板。
2. 加入 VELLUM 备份核心与设置入口（先本地，再 COS/OSS）。
3. 优化阅读计时与统计页面、验证大书加载路径。
4. 添加 Android 系统小组件并在模拟器安装验证。
5. 单独建立 `AiChatApp` 与 `inkqilin-ledger` 的 UI 决策摘要，按各自技术栈重构公共主题与高频页面。

## 已完成实现（本轮）

- 字体面板使用“内置 / 我的导入”两个静态分组的连续列表，移除无必要的内置/我的字体/全部分段切换；导入字体超过四个时才显示搜索，保留 Fanqie 阅读纸张的前景色计算。
- 笔记目录改为引用块、笔记正文、段落元信息和独立删除操作的卡片布局；空状态增加清晰的引导图标。
- 阅读统计改为今日目标卡、近 7 日柱状趋势和按书籍列表；原有统计 JSON 格式不变。
- 备份服务写入 Vellum 专属 ZIP 清单，支持 AES-256-GCM、路径穿越校验和 COS/OSS 签名上传；云密钥通过 `flutter_secure_storage` 保存。
- 书籍内容 JSON 解码迁移到 isolate，避免大书打开时在 UI isolate 同步 `jsonDecode`。
- Android 小组件以中性卡片 + 主操作胶囊按钮打开 VELLUM，已完成 debug APK 构建和模拟器安装。
- 云备份设置页已接入云端对象列表、最近十项展示和按项下载恢复；读取动作保持显式触发，避免打开设置页就发起网络请求。
- 应用壳层主题使用温暖羊皮纸与暖炭黑：浅色背景 `#F7F3ED`、卡片 `#FFFDF8`、文字 `#2B2723`、次要文字 `#756C65`、分隔线 `#E4DCD3`；深色背景 `#151311`、卡片 `#211E1A`、文字 `#F5EFE7`、次要文字 `#B6AAA0`、分隔线 `#443A33`。浅色交互强调色为陶土红棕 `#A95C46`，深色为 `#D8896C`。
- 阅读页增加轻量计时胶囊，展示本次阅读与今日累计时间；计时暂停、后台落盘和统计详情继续由原有服务统一管理。

## 持续 UI 打磨（2026-10-06）

- 阅读器设置的每个子页在切换时回到顶部，避免保留上一页滚动偏移导致标题返回键落在滚动视口之外；返回、关闭、分组选项和字号控制统一采用至少 44 dp 的触摸热区。
- 设置页的分组列表使用独立卡片表面承载条目，页面背景与条目背景分离，确保浅色和深色模式下都有清晰的信息层级。
- 书库继续使用响应式列数和封面比例：窄屏优先保证封面可读，平板与桌面逐步增加列数；长标题与元数据统一省略，避免网格出现横向溢出。
- 笔记卡片使用轻微纸面对比、引用块和独立删除热区；目录搜索步进、紧凑目录关闭和笔记删除均保持 44 dp 触摸目标，避免窄屏误触。

## 阅读页与应用壳层统一（2026-10-06）

- 复核番茄解包资料后保留其机制：正文纸张可独立选择，阅读菜单覆盖在正文之上，章节、进度、书签和设置共享当前阅读状态；不复制番茄代码或品牌资源。
- VELLUM 的交互强调色统一使用应用壳层陶土红棕（浅色 `#A95C46`、深色 `#D8896C`）。番茄橙色仅作为逆向参考 token 保留，避免阅读页与书库/设置页出现两套品牌色。
- 阅读纸张、正文墨色和暗色对比度继续由 `ReaderBackground` 与 Fanqie 标准纸张 token 管理；这样用户的阅读舒适度设置不会被壳层统一色彩覆盖。

## 目录与已读位置导航重构（2026-10-06）

- 目录继续使用固定半屏抽屉，正常状态不扩展到全屏；搜索时仅为键盘输入保留临时的安全扩展。目录、书签和笔记仍是三个同级入口。
- 目录增加固定“继续阅读”进度卡，同时显示全书进度、当前章节进度和页码/百分比；章节行保持番茄参考的 54dp 高度，并增加当前章节左侧陶土色标记、当前/已读/未读状态和至少 44dp 的返回当前按钮。
- 章节点击语义固定为：当前章节恢复 `chapterPositions` 中的位置，其他章节、上一章/下一章和全书滑杆定位到章节首段；搜索、书签和笔记仍执行精确段落跳转。
- 底部滑杆改为全书连续进度，章节按钮负责边界跳转，进度栏同时显示当前章节标题、本章百分比和全书百分比。进度摘要为运行时派生对象，不改变阅读状态 JSON、书籍 JSON 或备份格式。
- 目录和分页跳转使用独立世代序号；新跳转会取消旧的异步分页并忽略旧动画完成回调，保持 anchored window 的 12 页首屏与 100 页后台预取策略。
- 番茄资料仅用于学习固定行列表、当前项自动定位、悬浮返回当前和页/百分比进度机制；未复制代码、品牌资源或数据结构。

## 温暖羊皮纸主题最终决策（2026-10-06）

- 字体选择页和字体管理页都从主题语义 token 解析背景、卡片、文字、分隔线和交互色；字体选择页的当前项同时使用陶土色填充、细边框、名称高亮和勾选图标。
- 阅读纸张继续保留番茄标准白、米黄、绿、蓝、夜间和炭黑色板；阅读纸张与菜单壳层分离，字体预览即时反馈，交互热区保持至少 44dp。
- Android 小组件同步使用同一套暖色资源：浅色 `#F7F3ED/#FFFDF8/#A95C46`，深色 `#151311/#211E1A/#D8896C`，文字与 Flutter 壳层 token 对齐。
- 不迁移阅读状态 JSON，不改变备份格式，不改变字体存储格式；旧阅读纸张归一化逻辑继续只处理既有历史值。

## 阅读排版、字体列表与大书导航修复（2026-10-06）

- 笔记标记采用贴近段落末行的 `Stack` 覆盖层，不再为标记预留右侧正文宽度；正文换行、分页和无笔记状态保持一致，标记热区至少 44 dp 并提供段落语义标签。
- 章节导航只清理导航层：脚注解释、正文句子和过长说明从目录移除，正文、全文搜索和原始书籍 JSON 保留；附录、尾声、制作说明、作者页及其他结构化条目继续保留。MOBI 锚点在限定附近窗口内校正到真实标题段落。
- 大书分页的深跳阈值调整为 4,000 段；深跳先同步生成 12 页，再以可取消的定时任务扩展到 100 页。每次新跳转或重新排版都会使旧分页世代失效，避免旧任务覆盖新目标或在页面销毁后遗留定时器。

## 阅读状态与备份体验优化（2026-10-06）

- 阅读页底部电量图标根据 Android `BatteryManager.BATTERY_PROPERTY_CAPACITY` 分为 0/25/75/100 四档，低于 15% 使用系统警示色；应用回到前台时重新读取，非 Android 或暂不可用时保留文字状态并隐藏未知图标。
- 阅读页在非测试环境每分钟低频刷新一次电量，并只在数值变化时重建状态栏，覆盖长时间阅读过程中的电量变化。
- 下拉书签反馈采用渐进伸展的右侧书签带、轮廓/实心图标切换、状态胶囊淡入与轻微缩放动画；达到阈值后使用触感反馈，并用一次性消费标记避免滚动通知和指针抬起重复切换书签。
- 备份仍使用旧 ZIP/加密格式和路径安全校验，但新增“书籍与书库、阅读进度与设置、笔记、统计、写作、字体、应用设置”七类选择。所有本地创建、文件导出和 COS/OSS 上传共享同一筛选集合；清空选择会阻止创建，未开启加密时直接生成普通 `.zip`，加密包继续使用 `.vbackup`，旧备份恢复逻辑不变。
- 模拟器冒烟验证确认备份页的七类内容选择、陶土色复选框和关闭加密后的本地 ZIP 创建；验证产生的测试备份已从模拟器删除，截图与构建产物在收尾阶段清理。

## 动态书架小组件决策（2026-10-06）

- Android 小组件从单一“继续阅读”卡片改为 3×2 可伸缩书架；书架最多显示 5 本书，当前阅读书籍固定置首，其余沿用书库顺序。
- 书籍只同步 ID、标题、进度和当前标记；正文、笔记、密钥和备份内容不进入小组件快照。快照保存在应用私有目录，是可重建缓存，不属于备份格式或阅读状态迁移。
- 视觉使用彩色书脊、暖色层板和羊皮纸卡片，不加载封面缩略图，确保 RemoteViews 在不同桌面尺寸上稳定渲染；浅色/深色分别沿用 VELLUM 暖色 token。
- Flutter 通过 `vellum/device` MethodChannel 将快照原子写入原生私有文件，并通知 Provider 刷新所有实例。快照缺失、损坏或版本未知时显示空书架，不阻塞应用启动。
- 小组件任意位置统一打开 VELLUM 并恢复现有阅读位置，不新增按书籍深链路；阅读状态 JSON、书籍 JSON、备份格式和其他工程均不修改。
